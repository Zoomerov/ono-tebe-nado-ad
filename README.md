# Оно тебе надо

Проектная работа по макету Яндекс Практикума: страница аукциона вещей, в которые никто не верил.

Репозиторий: https://github.com/AhriEva/ono-tebe-nado-ad

## Технологии

Семантический HTML, CSS, Grid и Flexbox, локальные шрифты Raleway, организация классов по БЭМ. Макет рассчитан на ширину страницы 1100 пикселей.

## Просмотр

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны. Все пути к ресурсам относительные.
